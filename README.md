# FUTURE_DS_01 – Sales Performance Analysis

Sales performance and business analytics project completed for **Future Interns Data Science & Analytics Task 1**.

## Work Done

- Performed **Exploratory Data Analysis (EDA)**
- Analyzed monthly and yearly sales trends
- Calculated Year-over-Year (YoY) sales growth
- Compared sales and profit across categories
- Calculated profit margins
- Identified the top 10 highest-selling products
- Analyzed sales by **Region → State → City**
- Created visualizations using **Matplotlib**
- Built a **Power BI dashboard**
- Derived key business insights and recommendations

## Tools

**Google Colab | Python | Pandas | Matplotlib | SQL | Power BI**
